Python 零基础全套笔记（你所有提问汇总）
一、代码结构规范（你踩坑最多）
1. 什么时候末尾必须加冒号 : ？
只要下面有缩进代码块，末尾必须加冒号
包括：
- def 函数定义:
- if / elif / else:
- for / while 循环:
- try / except:
口诀：冒号 = 我要开始一块新代码块了
2. 缩进规则（你报错最多）
- Python 靠缩进区分代码块
- 必须统一 4 个空格
- 不能混用 Tab 和空格
- 缩进不一致 → 直接报错：IndentationError
3. def 函数后面为什么有 ()？
- () 是参数位
- 空括号 = 不需要传入数据
- 调用函数必须写括号 func()
- 只写 func 代表函数本身，不会执行
4. if __name__ == "__main__": 作用
这是程序入口
- 直接运行当前文件 → 条件成立，执行代码
- 被别人 import 导入 → 不执行
作用：代码既能当工具库，又能独立运行测试

二、异常处理（你学的两个核心错误）
1. ValueError
值错误：格式不对，无法转换
场景：输入字母、符号、空内容 → 转 int/float 失败
2. ZeroDivisionError
数学错误：除数为0
场景：运算合法、数字合法，但数学规则不允许
区分口诀
- ValueError：输入烂
- ZeroDivisionError：运算非法

三、if / elif / else 终极逻辑（你专门问过）
1. 能不能颠倒顺序？
互斥条件（>0、<0、=0）可以随便换
重叠条件绝对不能乱换
规则：严格、狭小的条件放前面，宽松条件放后面
2. 执行机制
命中一条，直接结束，不会再判断后面

四、f-string 格式化字符串（你专门问{}原理）
1. 什么是格式化字符串？
固定文字模板 + 动态变量填充
不需要拼接、不需要转字符串
2. {} 大括号作用
把变量/计算结果嵌入文字中
示例：
print(f"结果：{total}")
3. 什么时候必须用{}？
只要文字里有动态变化的数据就要用
4. 关键坑
不加 f → {} 只是普通文本，不会解析变量！

五、input() 原理（你问过）
1. 为什么 input() 能显示文字？
input 自带两步功能：
1. 先打印提示文字
2. 再等待用户输入
不是 print，是 input 自带功能
2. 提示文字和变量无关
input("请输入整数n")
引号里的 n 只是文字，删掉完全不影响程序
真正的变量是：n = int(input_str)

六、for 循环 + range 最全解释（你重点问的）
1. range 铁律
左包含，右不包含（包头不包尾）
range(1,11) → 1~10，永远取不到11
口诀：想要包含n，终点必须 n+1
2. for 循环变量为什么不用定义？
for 语法自动创建循环变量
for num in range(1, n+1)
num 每一轮自动赋值，无需提前声明
3. while 和 for 最大区别
- for：变量自动生成
- while：必须手动初始化计数器
4. print 缩进大坑（你踩过）
- print 在 for 内部：每次循环都打印
- print 在 for 外部：循环结束只打印最终结果

七、累加变量 total 原理（你问过）
1. 为什么 total = 0？
累加前盒子必须是空的，初始值一定是0
2. total = total + num
新值 = 旧值 + 当前数
简写：total += num
